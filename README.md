## 使用说明

### 如何查找资料

1. 先进入对应的学科目录。
2. 阅读该目录下的 `README.md`，确认课程体系和适用课程。
3. 根据课程名称进入具体课程目录。
4. 在教材、讲义、作业或往年考题等子目录中查找所需资料。

部分资料按学期、授课教师和考试类型分类，文件名中的年份通常表示学年开始的年份。例如，`2022-VA2-期末` 表示 2022—2023 学年的微积分 A2 期末考试。

### 关于试题与解析

仓库中的部分试题尚未配备答案，或可能存在扫描模糊、排版不完整等问题。欢迎在发现问题时提交 Issue，或贡献更清晰的试卷与解析。

## 参与贡献

欢迎通过以下方式帮助完善仓库：

- 提交新的课程资料、试题或参考答案；
- 提交更清晰的扫描件，替换质量较差的文件；
- 指出解析、课程分类或文件信息中的错误；
- 提交 Issue，反馈资料缺失或提出改进建议；
- 提交 Pull Request，直接完善目录说明或补充资料。

贡献资料时，请尽量注明课程名称、授课教师、学期和资料来源，并避免上传包含个人隐私的信息。

## 版权与使用

本仓库为开源学习资料整理项目，禁止以任何形式利用本仓库中的资源牟利。仓库内部分资料来自网络或其他同学的整理，版权归原作者或相关权利人所有。

如你认为仓库中的内容侵犯了你的权益，或希望撤下某项资料，请联系维护者，我们会及时核实处理。使用仓库资料时请遵守相关法律法规、学校规定及资料原作者的许可要求。
